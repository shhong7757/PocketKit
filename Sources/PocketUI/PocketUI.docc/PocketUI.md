# ``PocketUI``

SwiftUI 앱에서 자주 반복되는 미디어 UI 흐름을 가볍게 꺼내 쓰기 위한
컴포넌트 모음입니다.

## 개요

PocketUI는 앱이 소유한 항목을 그리드로 보여주고, 앱 화면 안에서 필요한
상호작용을 조립할 수 있는 SwiftUI UI primitive를 제공합니다.
