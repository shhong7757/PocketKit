# ``PocketUI``

SwiftUI 앱에서 자주 반복되는 미디어 UI 흐름을 가볍게 꺼내 쓰기 위한
컴포넌트 모음입니다.

## 개요

PocketUI는 앱이 소유한 미디어 항목을 그리드와 상세 화면으로 보여주고, 상세
콘텐츠를 확대해서 살펴볼 수 있는 SwiftUI 컴포넌트를 제공합니다.
